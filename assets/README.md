# assets/

Ноутбуки Jupyter (`.ipynb`) с воспроизводимым ходом решения. Число файлов свободное.

По смыслу желательно покрыть: EDA → предобработка → признаки/классификатор →
онлайн-симуляция (`run.py`/`score.py` → `results/metrics/`) → сравнение ЭЭГ / NIRS / гибрид.

Сохраняйте выводы ячеек. Не коммитьте `.mat`. Метрики сдачи — только через замороженный каркас.
