# EDA к RESEARCH_REPORT.md

Скрипты быстрого анализа 56 сессий `data/train` (numpy + scipy). Запуск из этой папки:

| Скрипт | Что считает | Раздел отчёта |
|---|---|---|
| `psd.py` | отношения мощности Л/П к покою на C3/C4 по частотам (запускать в папке с .mat) | 5.2.3 |
| `fes.py` | спектральные пики, связанные с классом (обнаружение ~83 Гц) (запускать в папке с .mat) | 5.2.3 |
| `fes2.py <data_dir> <out.jsonl>` | AUC мощности 81.5–85.5 Гц (воображение vs покой, Л vs П), временной ход | 5.2.3 → `fes2.jsonl` |
| `fes3.py <data_dir> <out.jsonl> <i0> <i1>` | μ-ERD ранний/поздний, стратификация по артефакту ФЭС | 5.2.6 → `fes3.jsonl` |
| `conf.py <data_dir> 0 56 conf.npy` | AUC Л vs П: ГЭОГ f7−f8, μ/β C3−C4, α o1−o2, 30–45 Гц c7−c8 | 5.2.4 |
| `nirs.py <data_dir>` | grand average HbO/HbR по классам и полушариям, AUC латерализации | 5.2.5 |
| `hb.py <data_dir>` | проверка разметки HbO/HbR (кардиальная и медленная мощность) | 5.2.5 |

Это **офлайн-анализ** по размеченным сегментам, а не онлайн-классификатор, поэтому требования причинности ТЗ §3.4 к нему не относятся. Не переносите этот код в `classifier.py` без проверки.
